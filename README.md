# Digital Marketing Campaign Conversion Prediction

## Overview
A machine learning project that predicts whether a
customer is likely to convert based on digital
marketing campaign data.

## Objectives
- Analyze customer and campaign data.
- Perform exploratory data analysis.
- Identify factors influencing conversion.
- Build a machine learning classification model.
- Predict customer conversion through a Streamlit UI.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit

## Project Features
- Data preprocessing
- Exploratory Data Analysis
- Machine Learning Model
- Conversion Prediction
- Interactive Streamlit Interface

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
